# Отбор строк по `ln_x2.notna()`: аудит четырёх депозитов и одна снятая угроза

2026-10-21. Найдено при замере времени ЦПУ-прогона для развёртки по порогу, не целенаправленно.

## Дефект

`notebooks/data/processed/test.csv` (от 19 июня, не менялся) содержит **8103** строки с непустым
`ln_x2`, но измерений среди них **5608**. Остальные **2495** — вспомогательные строки
(`source` = `aux_only` / `aux_only_gamma`, несут `has_T_m`), и `ln_x2` у них **РОВНО 0.0, а не
NaN**, поэтому `notna()` их пропускает. `has_solubility` отбирает ровно верные 5608 — проверено,
что это тот же САМЫЙ набор строк, а не просто то же число.

Дефект молчаливый по построению: он не падает, а возвращает MAE, посчитанный с 31% нулей, который
выглядит как обычное число.

Исправлено в пяти скриптах (`run_sigma_displacement_geometry`, `run_segment_convergence_audit`,
`run_sigma_profile_residual`, `run_sigma_role_injection`, `run_donor_window_rescore`): отбор по
`has_solubility` с запасным путём и assert, падающий на заполнителях.

## Три разных режима отказа, а не один

| скрипт | как использовалось | что портило бы заражение |
|---|---|---|
| `segment_convergence_audit` | `df` -> построчный MAE | среднее по строкам |
| `sigma_role_injection` | `df` -> построчный MAE | среднее по строкам |
| `sigma_profile_residual` | `scored` -> множество молекул | РАСШИРЯЕТ пул (+2487 растворяемых) |
| `donor_window_rescore` | `scored` -> `n_rows`, веса растворителей | ВЕСА, в пользу воды |

## Аудит депозитов

| депозит | проверка | вердикт |
|---|---|---|
| `results/segment_convergence/` | 140200 строк = 5 сидов x 5 значений счёта x 5608 | **ЧИСТ** |
| `results/sigma_role_injection/` | `n_rows_per_arm` = 5608; контроль 1.9274867 против `block1_cells.json` `grounded_a.mae.mean` | **ЧИСТ** |
| `results/donor_window_rescore/` | у всех 31 растворителя `n_rows` совпал с чистым счётом (31 из 31); воды в депозите нет | **ЧИСТ** |
| `results/sigma_profile_residual/` | 126 молекул, из них **55 (44%) не встречаются ни в одной чистой строке** | **ЗАТРОНУТ** |

Прошлые прогоны спасались тем, что их запускали с `--max-rows 5608`, и граница случайно совпала с
границей источника в файле. Дефект был направлен в будущее.

Отдельно важно: донорный депозит **чист**, и это проверено до того, как придержанное письмо по
§3.3 куда-либо пошло.

## Что сдвигается в затронутом депозите

Обогащение остатка, медианы по молекулам:

| величина | весь пул (опубликовано) | только на поверхности | вне поверхности |
|---|---|---|---|
| донорное окно, растворяемое | **4.38x** | **3.97x** | 5.01x |
| акцепторное окно, растворяемое | 2.39x | **2.03x** | 4.05x |
| неполярное ядро, растворяемое | 0.91 | **0.88** | 0.95 |
| донорное окно, растворитель | 4.22x | **3.78x** | 4.94x |

Посидово на поверхности (донор растворяемого): 3.79 / 3.08 / 4.12 / 3.97 / 4.33 — знак не меняется,
все далеко выше единицы.

**Вывод: заявление выживает, число уменьшается примерно на 10%.** Внешние молекулы были обогащены
СИЛЬНЕЕ (5.01 против 3.97), поэтому их включение завышало результат. Печатать надо 3.97x на
чистом пуле из 71 молекулы, а не 4.38x на 126.

## СНЯТАЯ УГРОЗА: Kish n = 6.38 был артефактом этого дефекта

Записанное ранее «66 растворителей, вода несёт 36.2%, топ-5 несут 62.0%, Kish эффективное
n = 6.38» измерено на ЗАРАЖЁННОМ наборе строк. Проверка:

| | чистые 5608 | заражённые 8103 |
|---|---|---|
| вода, строк | 436 | 2923 |
| вода, доля | **7.77%** | **36.07%** |
| растворителей | 70 | 72 |
| Kish эффективное n | **17.02** | ~6.4 |

36.07% на заражённом наборе воспроизводит записанные 36.2% (остаток — дальнейшая фильтрация по
наличию эталонного профиля). То есть это не две разные законные поверхности, а одна чистая и одна
заражённая.

Следствие для статьи: угроза «эффективное n всего 6.4, а вода треть веса», названная главной
уязвимостью предлагаемой спины, **не существует на чистой поверхности**. Там Kish n = 17.02 и вода
7.77%, что и было независимо измерено в `results/sigma_location_robustness/`.
