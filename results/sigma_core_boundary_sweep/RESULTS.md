# Цену определяет ПЕРЕСЕЧЕНИЕ σ_hb, а не расстояние за ним

Прогон 2026-10-21 на ЦПУ, `scripts/analysis/run_sigma_core_boundary_sweep.py`; чтение —
`read_core_boundary_sweep.py`, закоммичен вместе с кодом ДО чисел (`45845b3`). Правило, пороги и
обязательные к печати величины — в `PRE_DECLARATION.md`, записаны до написания кода.

## Чем этот прибор отличается от провалившегося

Развёртка по ВНЕШНЕЙ границе угла (`results/sigma_corner_threshold_sweep/`) оказалась
недействительной: она согласовывала Хеллингер, а Хеллингер **не согласует массу** — Спирмен(порог,
переложенная масса) = −1.000 ровно как у штрафа. Здесь исправлено обоё:

| | развёртка по углу | эта развёртка |
|---|---|---|
| что согласовано | Хеллингер (масса плыла, −40%) | **полная вариация** = чистая переложенная масса |
| что отпущено | масса (не печаталась) | **Хеллингер (печатается)** |
| ширина назначения | плыла 32 → 4 бина | **постоянна, 8 бинов** |
| как заданы окна | сравнением float | **по индексам бинов** |

## Предзаявленное правило: все четыре условия выполнены

| условие | порог | получено | |
|---|---|---|---|
| Δ = ВНЕ − ВНУТРИ | >= 0.15 | **+0.3593** | да |
| знак Δ по сидам | >= 4 из 5 | **5 из 5**: +0.371 / +0.386 / +0.384 / +0.330 / +0.326 | да |
| нет тренда внутри группы ВНЕ | \|Спирмен\| < 0.5 | **+0.200** | да |
| порастворительная знаковая доля > 60% | >= 4 сидов | **5 из 5**: 74.6 / 66.7 / 68.3 / 71.4 / 68.3% | да |

**ВЕРДИКТ: СТУПЕНЬКА НА σ_hb.** Конкурирующая ветвь «плавный рост с расстоянием» требовала Спирмена
>= +0.8 по всем шести окнам; получено **+0.771**, и она НЕ прошла. Правило различило две гипотезы, а
не приняло любую подвернувшуюся.

Порастворительные медианы разностей: +0.405 / +0.439 / +0.356 / +0.328 / +0.445 при n = 63.

**Кластерный интервал** (растворитель, 4000 розыгрышей, сид 20261021):
Δ = **+0.3593, CI95 [+0.2039, +0.5200]** — ноль исключён с запасом. Для сравнения, равновесный
контраст ядро-против-угла из депозита давал [+0.007, +0.571], то есть исключал ноль на волосок;
здесь нижняя граница отстоит от нуля в 29 раз дальше. Это самое прочное число ветки.

Обе конкурирующие ветви правила провалились явно: «плавный рост» — по обоим своим условиям
(Спирмен по шести +0.771 < 0.8; внутри группы ВНЕ +0.200 < 0.5), «расположение несущественно» —
тоже по обоим (|Δ| = 0.359 > 0.15; |Спирмен| = 0.771 > 0.5).

## Почему знаковая доля здесь важна отдельно

Порог 60% был поднят осознанно: в депозитном контрасте ядро-против-угла знаковая доля составляла
**54.0%** при 350 парах, то есть «в среднем дороже» было хвостовым свойством, а не свойством
типичного растворителя. Здесь 66.7-74.6% на всех пяти сидах — то есть эффект несёт большинство
растворителей, а не хвост. Это и есть разница между двумя находками, и она измерена, а не заявлена.

Межквартильные размахи порастворительных разностей по-прежнему слегка накрывают ноль
(напр. [−0.039, +0.993] на сиде 42), поэтому формулировка — «большинство», а не «все».

## Что это значит

σ_hb = 0.0084 — не выбранное число, а параметр замыкания: порог, на котором включается
водородносвязанный член COSMO-SAC. Измеренное утверждение: **цена неверной спецификации
определяется тем, пересекла ли смещённая масса этот порог, и почти не зависит от того, насколько
дальше она ушла.** Первое же окно за порогом (0.009-0.012) уже стоит в 6-9 раз дороже внутренних, а
дальше тренда нет (Спирмен +0.200).

Это объясняет и провал развёртки по внешней границе: все её окна лежали ЗА σ_hb, то есть она
двигала границу внутри области, где цена уже вышла на плато.

## Оговорки, печатаемые вместе с результатом

1. **Вода исключена**, а она самый жёсткий растворитель этого замыкания: деградация IDAC
   сосредоточена на ней, в чистом наборе строк она несёт 7.77%. Результат — о 63 растворителях без
   воды.
2. **Не отделено** «σ_hb особая» от «за ядром лежит мало массы профиля». Масса выученного профиля
   сосредоточена в ядре, и σ_hb примерно совпадает с плечом распределения. Для разделения нужен
   стимул с иным распределением массы либо прогон при сдвинутом `cosmo_sac_sigma_hb` — то есть
   другое замыкание. Оговорка записана В ПРЕДЗАЯВКЕ, до чисел.
3. **Хеллингер отпущен** и идёт немонотонно (1.63 → 1.85 → 2.07 → 2.79 → 3.19 → 3.25). Согласована
   масса, не H. Два прибора вместе берут вопрос в вилку: при зажатом H ответа не было, при зажатой
   массе он есть.
4. Ширина окна (8 бинов) и выбор источника (всё ядро) не проверялись.
