## Paired result

Both arms are scored on the same n=44 molecules, so the contrast is the per-molecule
paired difference `d_i = ρ_i(free) − ρ_i(fixg)`; each arm's marginal drop-one spread
(~0.014) badly overstates the uncertainty of the difference.

| | epoch 4 | epoch 8 |
|---|---|---|
| ρ_fixg | 0.7890 | 0.7768 |
| ρ_free | 0.7938 | 0.7923 |
| **Δρ (paired)** | **+0.0048** | **+0.0155** |
| 95% bootstrap CI | [+0.0016, +0.0082] | [+0.0110, +0.0199] |
| molecules favouring fixg | 27/44 (p = 8.7e-02) | **39/44 (p = 7.0e-08)** |

Trajectory over those 4 epochs: Δρ growth **+0.00267/epoch**, ρ_fixg descent
−0.00303/epoch.

**Gate decision: CONTINUE.** Δρ = 0.0155 clears the 0.01 continue bar, the gap is
growing (roughly tripled between the two checkpoints), and the CI excludes zero.

## Projection to epoch 24

- Δρ → **+0.058**, clearing the 0.05 GO bar.
- ρ_fixg → **0.728**, still above the wrong-molecule permutation band (0.6505); crossing
  it would need ~42 more epochs, and only 16 remain.

GO requires **both**. So the projected verdict is **PARTIAL**: the residual measurably
pulls the latent toward the reference profiles, but not far enough for σ̂ to become
molecule-specific. This is exactly the outcome the original pre-registration named as its
honest most-likely case.

Note also that both arms drift down from the 0.8156 origin (−0.032 for free by epoch 8).
Continued training alone moves ρ; only the matched control separates that drift from the
residual's own contribution. An absolute threshold would have credited the residual with
the whole −0.039.

## Correction recorded

An earlier reading of this gate reported Δρ = +0.0034 and "contrast is not growing". That
was an artifact: the rolling checkpoint is rewritten only every `--checkpoint-every`
epochs, so snapshots `fixg_5` … `fixg_9` are byte-identical copies of the epoch-4 state
(md5 `b679b6f7…`) while `free_9` had already advanced to epoch 8. The comparison therefore
paired fixg@epoch-4 against free@epoch-8. `scripts/experiments/fix_g_paired_delta.py` now
reads each checkpoint's true `(phase, epoch)` from its `resume_state` and refuses
mismatched pairs.
